# 투자 노트 (옵시디안 볼트)

이 저장소는 n8n "투자 뉴스 - 게시" 워크플로가 하루 4번 노트를 커밋하는 옵시디안 볼트입니다.

| 폴더 | 누가 쓰나 | 내용 |
|---|---|---|
| `자동/일일/` | n8n (매 회차 덮어씀) | `2026-11-13 시장`처럼 하루 브리핑과 기사 목록 |
| `자동/기사/YYYY-MM/` | n8n (매 회차 덮어씀) | 사건마다 대표 기사 1개. 파일 이름 끝의 `~abc123`은 같은 사건을 다시 찾는 꼬리표 |
| `종목/` | n8n은 처음 한 번만 만듦 | 종목별 노트. "내 메모" 아래에 자유롭게 기록 |
| 그 밖의 폴더 | 나 | 직접 만드는 노트 |

`자동/` 안의 노트는 다음 게시 때 덮어써지므로 고치지 말고, 메모는 종목 노트나 다른 폴더에 쓰세요. 브리핑은 AI 요약이고, 기사 노트의 `논조`는 기사 논조 분류일 뿐 투자 의견이 아닙니다.
